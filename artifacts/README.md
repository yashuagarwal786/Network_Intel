# Artifact index

- `brand/` — approved reusable product identity assets.
- `cycle2/` through `cycle6/` — verification outputs grouped by implementation cycle.
- `cycle6-audit/` — screen-by-screen cycle 6 audit captures.
- `design-qa/` — design QA comparison and implementation images.
- `redesign/` — current redesign captures and verification reports.
- `legacy-ui/` — older baseline and golden-flow captures.
- `first-round/`, `sih-presentation/`, and `hackathon-pack/` — submission material.
- `judge-video/`, `launch-video/`, and `premium-launch/` — video and launch material.
- `sample-api/` — captured API examples.

Generated files should be added to the matching folder instead of directly under `artifacts/`.
